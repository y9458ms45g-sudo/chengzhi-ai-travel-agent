# 城知 · 项目简介

**一句话**：基于大模型ReAct架构的AI文旅Agent，自动为用户生成个性化旅游攻略。

## 解决什么问题
- 游客攻略信息碎片化，需要在多个App间交叉对比
- 天气、路况、景点、预算等实时数据分散在不同服务商
- 中小城市和非遗文化缺乏数字化传播

## 核心功能
1. **6工具自主调度**：天气/路况/知识库/联网搜索/景点/预算，LLM自主决定调用顺序
2. **三段式Agent**：Planner拆解 → Executor执行（ReAct循环） → Reflector校验
3. **多城市协作**：最多3个城市Agent并行收集信息，总控官整合行程
4. **城市IP人格化**：川渝11个城市IP（渝渝、蓉蓉、山山等），全国60+城市关键词路由
5. **非遗文化墙**：川江号子、川剧变脸、铜梁龙舞、荣昌折扇等
6. **团建方案+预算测算**：按城市消费档拆分餐饮/住宿/门票/交通

## 技术栈
Python · FastAPI · DeepSeek大模型 · ChromaDB · SQLite · 原生HTML/JS · 和风天气 · 高德地图 · 博查搜索

## 工程亮点
- 自己实现ReAct循环（未依赖LangChain/LangGraph）
- 句式NLP区分出发地/目的地
- 工具10秒硬超时+异常降级
- 41条测试用例100%通过
- 流式输出（SSE）
- 会话持久化+上下文裁剪
