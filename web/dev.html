🚀 开发者日常工作流

  1. 改前端 UI / 文案 / 样式 → 编辑 web/index.html（或 admin.html），浏览器按 Ctrl+F5 刷新即生效，不用重启。
  2. 改后端逻辑 / 工具 / 提示词 → 编辑 app/ 下 .py，必须重启后端（见上方"重启后端"）。
  3. 测城市识别 → 终端跑 python -m tests.run_eval --fast，应 100% 通过。
  4. 看用户在聊什么 → 管理后台 → 会话列表。
  5. 找答得差的 → 管理后台 → 差评工单。
  6. 发布前 → 点"下载 chat.db"备份。

📁 关键文件位置

  • 用户端页面：web/index.html
  • 管理后台：web/admin.html
  • Agent 主循环：app/agent/executor.py
  • LLM 调用+重试：app/llm.py
  • 内容安全：app/safety.py
  • 数据存储：app/data/chat.db
  • 接口 Key：.env（不要提交/外发）
